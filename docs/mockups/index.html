Six ways to dress the bazaar that remembers.

Same inventory, same soul — six visual directions. Every design keeps the invariants visible in the UI: sold listings stay, conversations go public, trust is a number backed by evidence, no payments.

What must survive every redesign: the log line on every card, the sold-but-browsable listing, the public-conversation signal, the two-sided trust chip, and zero payment UI. If a design drops these, it's wrong — no matter how pretty.
